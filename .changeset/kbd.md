New `Kbd` primitive: a key the user presses, drawn as a keycap on a native `<kbd>`. It's sized in `em`, so it matches the text it sits in. Text on the keycap is 4.5:1 and its lower edge 3:1 in every brand and mode. For a combination, wrap one Kbd per key in a plain `<kbd>`.
