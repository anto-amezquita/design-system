New `TopNav` pattern: the bar across the top with brand, main navigation and actions. From 1024px it shows NavigationMenu. Below that, a Menu button opens a Drawer with the same items, so there's one list and one "Main" navigation on the page at a time. The current link is marked in both, following a drawer link closes it, and the bar can be sticky.
