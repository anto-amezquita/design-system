New `FileUpload` primitive: pick files with a real (visually hidden) file input or drag them in. Type, size and count limits turn files away with a reason each; chosen files are listed with their size and a remove button named after the file, and focus moves sensibly after removing. A polite status announces what was added, removed or turned away. Field's label now has an id (`<id>-label`) so controls can point at it. No new tokens.
