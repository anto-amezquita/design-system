New `CodeBlock` primitive: code in the monospace face inside a `figure` named by its `filename` or `language`, with a Copy button that confirms "Copied" and announces it, optional `lineNumbers` (not read out, not selectable) and `highlight`ed lines (a `<mark>` with a bar). Long lines scroll sideways in a keyboard-reachable ScrollArea, or `wrap`. No syntax colouring yet.
