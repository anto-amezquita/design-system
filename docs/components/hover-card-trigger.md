# HoverCardTrigger

> Sub-component of HoverCard.

- Tier: composition
- Storybook: `Components/HoverCard`
- Import: `import { HoverCardTrigger } from '@amezquita/design-system/components/composition/HoverCard'`

## Props

| Prop | Type | Description |
|---|---|---|
| `children` | `React.ReactElement` | The link or button it previews. Required: the trigger keeps its own role and name. |

Also accepts all props of: `React.HTMLAttributes<HTMLElement>`

## Usage example

See `HoverCard`'s own usage example — HoverCardTrigger is one of its sub-components, not used standalone.
