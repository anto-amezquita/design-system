# SideNavTrigger

> Sub-component of SideNav.

- Tier: patterns
- Storybook: `Patterns/SideNav`
- Import: `import { SideNavTrigger } from '@amezquita/design-system/components/patterns/SideNav'`

## Props

| Prop | Type | Description |
|---|---|---|
| `aria-label?` | `string` | Accessible name for the icon-only hamburger button. Defaults to "Open navigation". The button opens SideNav's drawer, and hides itself from 1024px up, where the inline SideNav or the header's NavigationMenu takes over. |
| `className?` | `string` |  |

## Usage example

See `SideNav`'s own usage example — SideNavTrigger is one of its sub-components, not used standalone.
