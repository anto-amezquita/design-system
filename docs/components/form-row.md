# FormRow

> Sub-component of FormLayout.

- Tier: patterns
- Storybook: `Components/FormLayout`
- Import: `import { FormRow } from '@amezquita/design-system/components/patterns/FormLayout'`

## Props

| Prop | Type | Description |
|---|---|---|
| `columns?` | `2 \| 3` | Fields side by side when there is room: 2 (default) or 3. They stack in a narrow container. |

Also accepts all props of: `React.HTMLAttributes<HTMLDivElement>`

## Usage example

See `FormLayout`'s own usage example — FormRow is one of its sub-components, not used standalone.
