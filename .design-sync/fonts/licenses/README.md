# Font licences

Every font self-hosted for `/design-sync` is under the SIL Open Font
License 1.1, which asks that the licence travel with the font files. Each
file here is that family's `OFL.txt`, copied unchanged from the official
Google Fonts repository (`github.com/google/fonts`, `ofl/<family>/OFL.txt`),
with its own copyright line.

|---|---|
| `../Archivo-*.woff2` (demo-cool headings) | `Archivo-OFL.txt` |
| `../AtkinsonHyperlegibleNext-*.woff2` (demo-cool text) | `AtkinsonHyperlegibleNext-OFL.txt` |
| `../AtkinsonHyperlegibleMono-*.woff2` (demo-cool code) | `AtkinsonHyperlegibleMono-OFL.txt` |
| `../BricolageGrotesque-*.woff2` (demo-warm headings) | `BricolageGrotesque-OFL.txt` |
| `../InstrumentSans-*.woff2` (demo-warm text) | `InstrumentSans-OFL.txt` |
| `../Fraunces-*.woff2` (demo-soft headings) | `Fraunces-OFL.txt` |
| `../Nunito-*.woff2` (demo-soft text) | `Nunito-OFL.txt` |
| `../JetBrainsMono-*.woff2` (code, base and brands) | `JetBrainsMono-OFL.txt` |
| `../SchibstedGrotesk-*.woff2` (portfolio) | `SchibstedGrotesk-OFL.txt` |
